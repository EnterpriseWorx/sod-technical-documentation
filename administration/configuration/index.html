Configuration

The Configuration page controls when VerityRisk loads source data and how long snapshots are kept.

Permission: AdminConfigurationUpdate

Open Configuration

  • Navigate to Administration >> Configuration.
Field Editable Description
Load Schedule Yes Cron expression for the permission and violation load. The default is 0 5-20 * * * (hourly from 05:00 to 20:00).
Load Schedule Description No Human-readable form of the load schedule
Snapshot Schedule Yes Cron expression for database snapshots. The default is 0 4 * * * (daily at 04:00).
Snapshot Schedule Description No Human-readable form of the snapshot schedule
Snapshot Retention Days Yes How long snapshots are kept. The default is 180.

Update the schedule

  • Edit Load Schedule, Snapshot Schedule, and Snapshot Retention Days as needed. Use standard five-field cron syntax.
  • Click Save.
  • Confirm that the description fields update to match the new expressions. A Configuration Updated message confirms the save.

Warning

An invalid load schedule is rejected. Correct the cron expression and save again.

The load processes every active source, then recalculates violations against the current ruleset.
