Licence

The Licence page shows the current VerityRisk licence.

Permission: AdminLicenceUpdate

View licence information

  • Navigate to Administration >> Licence.

  • The Licence Information table lists:

    Name Value
    Key Licence key
    Valid License Whether the current file is valid
    Expire Date Licence expiry date (yyyy-MM-dd)

Renew the licence

  • Click Update Licence.
  • Upload the .lic file you received by email.
  • Confirm that a License updated message appears and that Expire Date changes to the new date.
