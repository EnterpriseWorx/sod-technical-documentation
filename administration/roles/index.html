Roles

A role is a named set of permissions. Users receive access to VerityRisk screens only through the roles assigned to them.

Permission: AdminRoleUpdate

Note

Roles used as a rule Approver Role must include RuleMitigationApprove. See The Rule Violation Mitigation Approval Process.

Open the role list

  • Navigate to Administration >> Roles.
Column Description
Name Role name
Permission Count Number of permissions on the role
Active Whether the role can be assigned to users and selected as an approver

Add or edit a role

  • Click Add, or click Edit on an existing role.
  • Enter a Name.
  • Set Active. Inactive roles cannot be assigned to users.
  • Select the Permissions the role should grant. At least one permission is required.
  • Click Save. A Role updated successfully message confirms the change.

Note

Permission names in the picker match the values below. There are no extra descriptions in the application.

Permissions
