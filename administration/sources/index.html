Sources

A source is a Syspro instance that VerityRisk loads operator access from. Each active source has its own staging database. The scheduled load (see Configuration) pulls permission data from every active source, then evaluates it against the ruleset.

Permission: AdminSourceUpdate

Open the source list

  • Navigate to Administration >> Sources.
Column Description
Business Key Short code for the instance (also used as the business unit)
Business Unit Name Display name
Source Type Syspro7 or Syspro8
Is Active Whether the source is included in loads

Add or edit a source

  • Click Add, or click Edit on an existing source.

  • Complete the Edit Source form:

    Field Required Notes
    Business Key Yes Two-character code that identifies the instance
    Business Unit Name Yes Name shown in lists and reports (up to 100 characters)
    Staging Database Name Yes Database VerityRisk creates and uses for this instance (up to 100 characters)
    Source Type - Syspro7 or Syspro8. This controls how permission data is extracted.
    Is Active - Inactive sources are skipped during loads

  • Click Save. A Source updated successfully message confirms the change.

Note

Inactive sources are skipped during loads.

Source types

  • Syspro7 - permission data is extracted by the Syspro COBOL extractor into the staging database, then imported by VerityRisk.
  • Syspro8 - VerityRisk reads permission data with SQL from the Syspro database using the credentials you configure.

Configure credentials

  • On the source list, click Credentials.

  • Complete Edit Source Credentials:

    Field Required Notes
    Server Name (\ Instance Name) Yes SQL Server host and optional instance
    Database Name Yes Syspro database to read from
    Username Yes SQL login
    Password Yes SQL password

  • Click Test to verify the connection. A Connected to source successfully message means the credentials work.

  • Click Save.
