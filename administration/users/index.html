Users

The Users page is where administrators create application users and assign roles.

Permission: AdminUserUpdate

Note

A user can sign in only after at least one role is assigned.

Open the user list

  • Navigate to Administration >> Users.
Column Description
User Name Sign-in name
Authentication Type Internal User, Azure User, or LDAP User
Roles Active roles assigned to the user, separated by commas

Authentication types

Choose the type that matches how the person should sign in:

Type When to use Sign-in
Internal User (local) VerityRisk stores the username and password Username and password on the login page
Azure User The person uses Microsoft Entra ID (Azure AD) Azure sign-in, when Azure is configured for the site
LDAP User The person uses Active Directory / LDAP Username and password validated against LDAP

Note

You cannot convert a user from one authentication type to another. Create a new user of the correct type instead.

Add a user

  • Click Add Internal User, Add Azure User, or Add LDAP User.
  • Enter a Username.
  • For an internal user, enter a Password.
  • Assign one or more Roles. At least one role is required. Only active roles can be selected.
  • Click Save. A User updated successfully message confirms the change.

Edit a user

  • Click Edit.
  • Update the username, password (internal users), or roles.
  • Click Save.

Delete a user

  • Click Delete on the user row.

Warning

Deletion is immediate. There is no confirmation dialog.
