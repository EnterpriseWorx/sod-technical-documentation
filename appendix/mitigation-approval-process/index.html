The Rule Violation Mitigation Approval Process

VerityRisk has an optional opt-in mitigation approval process. This feature allows you to assign specific rules to an approval role, for better controls around rule violation mitigations.

Note

Approval is only applicable for the Mitigation By Operator method at this point in time.

For the day-to-day screens, see Cancel Mitigations and Approve/Reject Mitigations.

Creating an Approval Role

Any role that is assigned the RuleMitigationApprove permission is able to approve a mitigation for any rules that have this role as the Approver Role.

E.g. In this example I have created a custom role called Mitigation Approver that is assigned the RuleMitigationApprove permission. This role is able to approve mitigation requests for rules that have this role assigned as the Approver Role.

Assigning Approver Roles to Rules

Now if we edit an existing rule we can fill in the Approver Role field if violations of this rule require mitigation approval. If rule violations do not require approval we can set the Approver Role field back to No approver.

Note

Only roles with the RuleMitigationApprove permission are selectable in the Approver Role dropdown.

Creating a mitigation that requires approval

When you are performing a Mitigation By Operator, if the potential mitigation has an Approver Role assigned, then once the user selects Update Operator Mitigations the rule violation mitigations will be assigned to any user with the assigned Approver Role to approve or reject the mitigation. In this case any user with the custom Mitigation Approver role will be able to approve or reject the mitigation.

If you created a mitigation by mistake, open Cancel Mitigations. It shows the pending requests that you captured.

Note

You can only cancel mitigations that you created.

To cancel a mitigation waiting for approval, just select the mitigation(s) you want to cancel, add a comment if needed and click the Cancel button.

Approving a mitigation

If you log in as a user that has a role with the RuleMitigationApprove permission, then you can select the Approve/Reject Mitigations tab to approve or reject rule violation mitigations. In the same way as canceling mitigations, you just select the mitigations that you wish to approve (or reject), add an optional comment and click on the Approve or Reject button.

Note

Mitigations are marked Currently Mitigated on Mitigation By Operator and in the PowerBI SoD reports only after they are approved.
