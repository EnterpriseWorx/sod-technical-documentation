Approve/Reject Mitigations

Approve/Reject Mitigations is where users with an approver role accept or reject pending operator mitigation requests.

Permission: RuleMitigationApprove

Note

You cannot approve a request that you captured yourself. The original capturer can withdraw it on Cancel Mitigations.

Note

You only see requests for rules whose Approver Role is a role assigned to you. Location mitigations never appear here.

Open Approve/Reject Mitigations

  • Navigate to approvals >> Approve/Reject Mitigations.

The menu label includes a count of requests waiting for you, for example Approve/Reject Mitigations (5).

Column Description
Rule ID Rule the mitigation applies to
Business Unit Source instance
Operator Operator affected by the request
Ticket Number Ticket attached when the request was submitted
Approver Role Name Role required to approve the request
Action MitigationAdd or MitigationRemove

Only Pending requests are shown.

Approve or reject

  • Select one or more pending mitigations. You must belong to the Approver Role on each selected rule.
  • Optionally enter a Comment (up to 150 characters).
  • Click Approve or Reject.
  • Confirm the comment, the action, and the number of selected items.
  • Click Confirm Changes, or Back to return without deciding.

If nothing is selected, VerityRisk shows No mitigation approvals selected.

What happens next

Decision Result
Approve The add or remove is applied. The violation is marked Currently Mitigated (or no longer mitigated) on Mitigation By Operator and in the PowerBI SoD reports.
Reject The request is closed and access is not changed. The violation reappears on Mitigation By Operator.
