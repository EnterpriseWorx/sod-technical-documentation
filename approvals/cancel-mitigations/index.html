Cancel Mitigations

Cancel Mitigations lets you withdraw operator mitigation requests that you submitted and that are still waiting for approval.

Permission: RuleMitigateUpdate

Note

You can only cancel requests that you created. Approvers use Approve/Reject Mitigations instead.

Note

Location mitigations are not listed here. They apply immediately and cannot be cancelled through this page.

Open Cancel Mitigations

  • Navigate to approvals >> Cancel Mitigations.

The menu label includes a count of your pending requests, for example Cancel Mitigations (3).

Column Description
Rule ID Rule the mitigation applies to
Business Unit Source instance
Operator Operator affected by the request
Ticket Number Ticket attached when the request was submitted
Approver Role Name Role that must approve the request
Action MitigationAdd or MitigationRemove

Only Pending requests that you captured are shown.

Cancel a request

  • Select one or more pending mitigations.
  • Optionally enter a Comment (up to 150 characters).
  • Click Cancel.
  • Confirm the comment and the number of selected items.
  • Click Confirm Changes, or Back to return without cancelling.

If nothing is selected, VerityRisk shows No mitigation approvals selected.

Note

Cancelled requests do not change Currently Mitigated on Mitigation By Operator. The underlying violation reappears on that list so you can submit it again if needed.
