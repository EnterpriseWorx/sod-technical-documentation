Violation Explorer

Violation Explorer lets you test which segregation-of-duty rules would be violated for a proposed combination of groups, roles, and activities. Use it to explore access before it is granted, or to understand why an operator already appears as a violation.

Permission: RuleExplorerView

Note

This screen does not change mitigations or operator access. It only calculates what the current ruleset would report.

Open Violation Explorer

  • Navigate to Home >> Violation Explorer.

Calculate violations

  • Select a Business Unit. This loads the groups, roles, activities, and operators for that Syspro source.
  • Optionally select Load from Operator. The operator's current groups, roles, and activities are copied into the form so you can start from a real profile.
  • Adjust Groups, Roles, and Activities as needed. Groups is required.
  • Click Calculate Violations.

If nothing matches the ruleset, a No violations found message is shown.

Results

Column Description
Rule ID Rule that would be violated
Program A / Program B Programs on each side of the rule
Activities A / Activities B Activities on each side of the rule
Business Unit Source instance used for the calculation
Company Code / Company Name Company in which the conflict occurs
Access Type How the two sides of the rule are reached: Group, Role, or Hybrid
Access Code A / Access Code B Group or role that satisfies each side
Risk Rating Risk rating from the rule

You can search, filter, sort, and export the results.

Access types

  • Group - both sides of the rule are reached through group program grants.
  • Role - both sides are reached through role grants in the same company.
  • Hybrid - one side is reached through a group and the other through a role.
