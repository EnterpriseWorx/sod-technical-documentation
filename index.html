    VerityRisk User Documentation

    VerityRisk is a Segregation of Duties (SoD) application. It loads operator access from one or more Syspro sources, evaluates that access against a ruleset, and highlights conflicts. You can then mitigate those conflicts by location or by operator, with an optional approval process.

    Note

    Menu items are shown only when your role includes the matching permission. If a page described here is missing from your menu, ask an administrator to review your role.

    Using the application

    Most list pages share the same table tools:

    • Search filters every visible column.
    • Column filters narrow the list by a specific field.
    • Click a column heading to sort.
    • Clear Filter resets the current filters.
    • Export downloads the current view as an XLSX file.
    • Page size options are typically 10, 25, or 50 rows.

    Edit screens often open as a dialog over the list. Use the page back control or close the dialog to return to the list.
