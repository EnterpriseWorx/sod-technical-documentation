Mitigation By Location

Mitigation By Location applies a control to every operator at selected locations for a given rule.

Permission: RuleMitigateView to open the list. RuleMitigateUpdate to save location changes.

Warning

Location mitigations take effect immediately. There is no approval step.

Tip

Use Mitigation By Operator when you need to mitigate individual operators instead of whole locations.

Open the location list

  • Navigate to Mitigation >> Mitigation By Location.
  • The Mitigate By Location list shows rules and any locations already mitigated.
Column Description
Rule ID Rule being mitigated
Process Process the rule belongs to
Risk Rating Risk rating from the rule
Rule Access Risk Description of the access risk
Rule Program A Program on side A of the rule
Mitigated By Location Locations currently covered by this mitigation

You can search, filter, sort, and export this list.

Note

There is no Add action — you mitigate existing rules only.

Update locations for a rule

  • Click View on the rule. The Select Locations dialog opens.
  • Review the read-only rule fields.
  • Enter a Document Number (required, up to 50 characters).
  • Enter a Document Description (required, up to 2000 characters).

  • In the Locations table, select the locations that should be mitigated. Locations that are already mitigated are pre-selected.

    Column Description
    Location ID Internal identifier
    LocationCode Location code
    LocationName Location name
    Currently Mitigated Whether this location is already mitigated for the rule

  • Click Update Locations.

  • Confirm the change:

    • Locations Added and Locations Removed summarise the difference from the current assignment.
    • Click Confirm Changes to apply, or Back to return to the location list without saving.

A Mitigation by locations updated message confirms the save. If you did not change any locations, VerityRisk shows No mitigation locations changed.
