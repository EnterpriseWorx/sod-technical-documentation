Mitigation By Operator

Mitigation By Operator applies a control to specific rule violations for individual operators. Each change is recorded against a mitigation ticket.

Permission: RuleMitigateView to open the page. RuleMitigateUpdate to submit changes.

Note

If the rule has an Approver Role, the change waits for approval instead of applying immediately. See The Rule Violation Mitigation Approval Process.

Tip

Use Mitigation By Location when the same control should cover every operator at a location.

Open Mitigation By Operator

  • Navigate to Mitigation >> Mitigation By Operator.
  • The Mitigate By Operator page shows current violations. Rows that are already mitigated are pre-selected.
Column Description
Rule ID Rule that was violated
Rule Risk Rating Risk rating from the rule
Rule Access Risk Description of the access risk
Operator Full Name Operator with the SoD violation
Business Unit Source instance
Access Access pair that caused the violation
Ticket Number Ticket currently attached, if the violation is already mitigated
Approver Role Role that must approve changes, if the rule requires approval
Currently Mitigated Whether this violation is already mitigated

You can search, filter, sort, select all, and export this list.

Note

Violations that are waiting for approval are hidden from this list until they are approved, rejected, or cancelled.

Add or remove operator mitigations

  • Create an Active ticket on Mitigation Tickets if you do not already have one.
  • Select a Ticket Number. This field is required.
  • Select the violations that should be mitigated. Clear the selection for violations that should no longer be mitigated.
  • Click Update Operator Mitigations.

  • Confirm the change:

    • Operators Added is the number of newly selected, previously unmitigated violations.
    • Operators Removed is the number of previously mitigated violations you cleared.
    • Click Confirm Changes to submit, or Back to return without saving.

A Mitigation by operators updated message confirms the save. If you did not change any selections, VerityRisk shows No mitigation operators changed.

What happens after you confirm

Rule configuration Result
Approver Role is No approver The add or remove is applied immediately. Currently Mitigated updates on this page and in the PowerBI SoD reports.
Approver Role is set A pending approval is created. The violation stays off this list until an approver acts, or until you cancel it.
  • You can cancel your own pending requests on Cancel Mitigations.
  • Approvers act on Approve/Reject Mitigations.

The Action on a pending request is MitigationAdd or MitigationRemove, depending on whether you selected or cleared the violation.
