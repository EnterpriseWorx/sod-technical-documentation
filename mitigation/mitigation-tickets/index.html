Mitigation Tickets

A mitigation ticket is the control document you attach when you mitigate a rule violation by operator. Create the ticket first, then select it on Mitigation By Operator.

Permission: RuleMitigationTicketView to open the list. RuleMitigationTicketUpdate to add or edit a ticket.

Note

Location mitigations do not use tickets. They use a document number and description instead. See Mitigation By Location.

Open the ticket list

  • Navigate to Mitigation >> Mitigation Tickets.
Column Description
Ticket Number Identifier shown when mitigating by operator
Created By User who created the ticket
Active Whether the ticket can be selected for new mitigations

You can search, filter, sort, and export this list.

Add a ticket

  • Click Add.
  • Enter a Ticket Number (up to 100 characters).
  • Enter an Audit Control Description (up to 500 characters).
  • Leave Active on unless you are creating a ticket that should not be used yet. New tickets default to active.
  • Click Save. A Mitigation ticket updated message confirms the change.

Edit a ticket

  • Click Edit on the ticket.
  • Update the ticket number, description, or active flag.
  • Click Save.

Note

Only Active tickets appear in the Ticket Number dropdown on Mitigation By Operator. Deactivating a ticket records who deactivated it and when. Existing operator mitigations that already use the ticket are not removed.
